# PM午前Ⅱ演習アプリの初回開発

状態: 完了（2026-10-12、ローカル実装・検証・公開準備）

## 目的・合意

system-arch-trainingを参考に、2009年度以降の全17回のPM午前Ⅱを演習できる静的アプリを作る。GitHub Pages、ログインなし、ブラウザ保存。スマートフォン中心。

画像拡大と主操作の強調を採用。PCの2列配置・解説の見出し分割・追加のフォーカス装飾・読み上げ対応・保存失敗通知は不採用。2026-10-11に利用者が計画と実作業の開始を承認した。

## 対象

`src/`、`public/data/`、`sources/ipa/`、`scripts/`、`tests/`、`docs/product.md`、開発・公開設定。

## 手順

1. 製品仕様、変更管理、問題データ形式を準備する。
2. 2025年度秋期の公式PDFを取得し、25問を画像化・テキスト化し、公式正解を照合する。
3. 根拠を調べて解説を執筆し、執筆とは別工程で各問・各肢を確認する。
4. 参照元の画面を引き継ぎ、PM化・拡大・主操作の強調を実装する。
5. データ・採点・保存・主要操作・直接URL・スマートフォン表示を検証する。
6. 最新年度の見本を利用者レビューに提出する。レビューの修正はこの案件で扱う。
7. レビュー後、残り16回を同じ方法で収録・確認する。
8. 全425問の確認と公開準備を完了し、GitHub登録後に公開ワークフローでリリースする。

## 確認基準

原PDFと画像・補助テキストの意味の一致、問番号1〜25の連続、公式正解との一致、画像・図表の欠落なし、解説の根拠と全肢の説明、計算の再計算、出題当時の版・制度の扱いを確認する。補助テキストは要約を含み、表や図の出題本文は原画像を使う。各回の `sources/ipa/<id>/review.json` に確認結果と根拠を記録し、この案件の `review/<id>.json` に写しを残す。参考資料のURLは各問の公開JSONに記録する。

ブラウザでは狭い幅・広い幅で、選択／選び直し／確認後固定／移動／一括採点／クリアの中止と実行／チェックの独立性／再読み込み／年度移動／拡大の開閉と倍率を確認する。

## 進捗・確認結果

- 全回抽出で、2016年度春期問2の公式正解が取り消されていることを確認した。原画像は収録し、正解を捏造せず `answer: null` とする。取消理由を解説し、正誤・正解率の対象から除く。利用者が依頼した全回収録のための例外処理として実装する。

- 仕様・変更管理・開発コンテナ・CI・手動のPages公開設定を作成。
- 2025年度秋期25問を原本から切り出し、問題文・選択肢を転記し、公式正解と解説・参考資料を収録。
- 執筆後に全25問を確認。問12の選択肢末尾と問19の選択肢行の切り出し欠落を修正。図表と各肢の説明を照合し、問6・7・9を再計算した。記録は `review/2025-r07-aki.json`。確認したデータと画像のハッシュも記録し、内容変更後に古い確認記録を使えないようにした。
- 参照元の画面をPMに変更。画像拡大（1・2・3倍）、結果確認の強調、クリアの補助操作表示を実装。320×568では画像領域が押し潰される問題を発見し、高さ680px以下で上部をスクロール可能にして修正。
- 2026-10-12、開発コンテナ内で `npm test` の5件、`npm run build` のデータ検証・型チェック・本番ビルド、`npm run test:browser` の12件を実行し成功。日本語フォントを備えたChromiumで390×844・320×568・1280×900を確認。
- 静的HTTPサーバーでも年度の直接URLが200、JS/CSSと全25画像が取得可能であることを確認。`sources/`・`docs/`・`specs/`・`AGENTS.md`は404で配信されない。
- `python scripts/validate_data.py --release` が「全17回が未収録」で停止することも確認。見本の状態を初回リリースとして配信できないことを確認した。
- 日本語画面を目視。画像・解説・下部は参照元と同じスクロール領域。画面写真は `review/preview/`。iPhone Safari・Androidの実機検証は未実施。
- レビュー用の開発サーバーをコンテナで起動。URLは `http://localhost:5173/project-manager-training-1/`。ホストの5173番をループバックにのみ公開。
- 2026-10-12、最新年度の見本を利用者が承認し、残りの作業を進めるよう指示した。残り16回・400問の抽出・執筆・確認に進む。全回の確認、GitHubへの登録・公開は未実施。公開ワークフローは全17回を必須としており、見本だけではリリースしない。
- 利用者から開発コンテナを使用し、ホストLinuxにnpm等をインストールしないよう指示を受けた。以降の依存導入・実行はコンテナ内で行う。一時展開していた `/tmp` のNode環境と取得途中のnpmキャッシュは削除した。ホスト設定・システムパッケージの変更はない。

- 残り全16回の公式問題・正解PDFと400画像・OCR下書きの抽出を完了。2024年度と2023年度の各25問を転記・解説執筆後に別工程で照合し、レビュー記録とハッシュを保存して一覧に追加した。計算問題は再計算。未執筆回のOCR下書きは一覧には掲載しない。
- 2016年度問2の取消対応を実装。2024年度追加後のユニット5件・型・ビルドが成功し、取消の採点除外・拡大・チェック・再読み込みのブラウザ回帰テスト3条件（390×844、320×568、1280×900）も成功。

## 全回収録版の確認結果

- 2009〜2025年度の全17回・425問を収録し、解説と参考資料を作成。執筆後の別工程で原画像・補助テキスト・公式正解・各肢の解説を照合した。同じ問題の再出題でも選択肢の順を確認し、計算は再計算した。2009年度のインスペクション効果・増員、2010年度のEVM・期間配分、2011年度の人数推移・評価点・回収期間等も確認した。
- 画像の切り出しは2023年度問23・24、2020年度問10・19・20、2017年度問1〜3・21・22を修正し、全肢・図表の末尾を再確認。2021年度問15の誤答の説明、2017年度問19の復旧時間と問20のDAの説明を原本に合わせた。2011年度問24には当時の著作権保護期間50年と2018年の70年への延長を補足した。各回の具体的な照合結果は `review/<id>.json`。
- 現在の内容確認記録と本案件の写しが全17回で一致。問題データと425画像のSHA-256を記録した。`python scripts/validate_data.py --release` が全17回・425問、採点対象424問で成功。2016年度問2には架空の正解を設定していない。
- 開発コンテナ内で `npm test` の5件、`npm run build` のデータ検証・型チェック・本番ビルドが成功。`npm run test:browser` は390×844・320×568・1280×900の全69件が成功。全年度の425画像と公式正解による一括採点、再読み込み、年度間の保存分離・クリア、実際の取消問題、選択・誤答・確認後固定・拡大を検証した。
- ブラウザ検証の初回は実行中コンテナのChromium保存先が未指定で起動失敗。保存先指定後に再実行した。また追加した年度テストで採点後の「○」を問番号に含めて誤判定していたため、番号部分を対象に修正し全69件を再実行して成功した。製品の採点表示を変えて回避していない。
- SPAフォールバックのない静的HTTP配信で、17年度の直接URLが200、425画像が200で原ファイルと一致、JS/CSSが200、開発文書・原本・未知の年度が404であることを確認。結果は `review/static-pages.json`。全回版の `dist/` は約65MB。
- 日本語Chromiumで全年度一覧、取消問題、人数推移図のスマートフォン拡大を目視確認。画面写真は `review/preview/mobile-all-years.png`・`mobile-cancelled.png`・`mobile-diagram-zoom.png`。iPhone Safari・Androidの実機検証は未実施。
- ホストLinuxへの依存インストールは行わず、npm・Python依存・OCR・サーバー・ビルド・テストは開発コンテナで実行した。
