# PM午前Ⅱ演習アプリの初回開発

## 目的・合意

system-arch-trainingを参考に、2009年度以降の全17回のPM午前Ⅱを演習できる静的アプリを作る。GitHub Pages、ログインなし、ブラウザ保存。スマートフォン中心。

画像拡大と主操作の強調を採用。PCの2列配置・解説の見出し分割・追加のフォーカス装飾・読み上げ対応・保存失敗通知は不採用。2026-10-11に利用者が計画と実作業の開始を承認した。

## 対象

`src/`、`public/data/`、`sources/ipa/`、`scripts/`、`tests/`、`docs/product.md`、開発・公開設定。

## 手順

1. 製品仕様、変更管理、問題データ形式を準備する。
2. 2025年度秋期の公式PDFを取得し、25問を画像化・テキスト化し、公式正解を照合する。
3. 根拠を調べて解説を執筆し、執筆とは別工程で各問・各肢を確認する。
4. 参照元の画面を引き継ぎ、PM化・拡大・主操作の強調を実装する。
5. データ・採点・保存・主要操作・直接URL・スマートフォン表示を検証する。
6. 最新年度の見本を利用者レビューに提出する。レビューの修正はこの案件で扱う。
7. レビュー後、残り16回を同じ方法で収録・確認する。
8. 全425問の確認と公開準備完了後にリリースする。

## 確認基準

原PDFと画像・問題文・選択肢の一致、問番号1〜25の連続、公式正解との一致、画像・図表の欠落なし、解説の根拠と全肢の説明、計算の再計算、出題当時の版・制度の扱いを確認する。各回の `sources/ipa/<id>/review.json` に結果・参考資料・未解決点を記録し、この案件の `review/<id>.json` に写しを残す。

ブラウザでは狭い幅・広い幅で、選択／選び直し／確認後固定／移動／一括採点／クリアの中止と実行／チェックの独立性／再読み込み／年度移動／拡大の開閉と倍率を確認する。

## 進捗・確認結果

- 仕様・変更管理・開発コンテナ・CI・手動のPages公開設定を作成。
- 2025年度秋期25問を原本から切り出し、問題文・選択肢を転記し、公式正解と解説・参考資料を収録。
- 執筆後に全25問を確認。問12の選択肢末尾と問19の選択肢行の切り出し欠落を修正。図表と各肢の説明を照合し、問6・7・9を再計算した。記録は `review/2025-r07-aki.json`。確認したデータと画像のハッシュも記録し、内容変更後に古い確認記録を使えないようにした。
- 参照元の画面をPMに変更。画像拡大（1・2・3倍）、結果確認の強調、クリアの補助操作表示を実装。320×568では画像領域が押し潰される問題を発見し、高さ680px以下で上部をスクロール可能にして修正。
- 2026-10-12、開発コンテナ内で `npm test` の5件、`npm run build` のデータ検証・型チェック・本番ビルド、`npm run test:browser` の12件を実行し成功。日本語フォントを備えたChromiumで390×844・320×568・1280×900を確認。
- 静的HTTPサーバーでも年度の直接URLが200、JS/CSSと全25画像が取得可能であることを確認。`sources/`・`docs/`・`specs/`・`AGENTS.md`は404で配信されない。
- `python scripts/validate_data.py --release` が「全17回が未収録」で停止することも確認。見本の状態を初回リリースとして配信できないことを確認した。
- 日本語画面を目視。画像・解説・下部は参照元と同じスクロール領域。画面写真は `review/preview/`。iPhone Safari・Androidの実機検証は未実施。
- レビュー用の開発サーバーをコンテナで起動。URLは `http://localhost:5173/project-manager-training-1/`。ホストの5173番をループバックにのみ公開。
- **現在は最新年度25問の利用者レビュー待ち。** 残り16回・400問の収録、全回の確認、GitHubへの登録・公開は未実施。公開ワークフローは全17回を必須としており、見本だけではリリースしない。
- 利用者から開発コンテナを使用し、ホストLinuxにnpm等をインストールしないよう指示を受けた。以降の依存導入・実行はコンテナ内で行う。一時展開していた `/tmp` のNode環境と取得途中のnpmキャッシュは削除した。ホスト設定・システムパッケージの変更はない。
